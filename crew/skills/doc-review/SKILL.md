# Document review

1. Read the request and the document. For PDF and office files (docx, xlsx, pptx), read them with Python from the shell, using what is already installed.
2. Scope:
   - Content the request does not ask for is must fix.
   - Content the request asks for that is missing is must fix.
   - Never report as missing something the request did not ask for.
3. Facts: check each fact, number, and date against its source, or against an official source on the web when the document gives none. A wrong fact is must fix.
4. Consistency: the document does not contradict itself, and names, numbers, and terms are written the same way throughout.
5. Clarity: a sentence that can be read two ways, or that a reader cannot follow without asking, is must fix; a wording that is only nicer is minor.
