# Write

1. Read the request and the plan, and any source material they name. Write only what they ask for: no extra sections, examples, or topics, however useful they look.
2. Put the conclusion first, then what supports it. Say each thing once, and name exactly what you mean so it cannot be read two ways.
3. Every fact and number comes from a source you read or a result you ran; mark what you could not confirm "unconfirmed".
4. Match the format the request names. For PDF and office files (docx, xlsx, pptx), charts, and pictures, make them with Python from the shell, using what is already installed; when nothing installed can make the format, stop and say so instead of installing.
5. Keep the document's own style the same throughout: one way of writing headings, numbers, dates, and terms.
6. Read the file you made once more and confirm it opens and holds what you meant.
