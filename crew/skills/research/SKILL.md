# Research

1. When the question touches the project, such as a dependency's version, read what the project uses first and state each finding against it.
2. Prefer official sources: the maker's own site, its specification, its documentation, its release notes. Confirm each key fact in two official places when they exist. When sources disagree, report both and mark the point "unconfirmed".
3. Read web pages with WebFetch; when a page comes back empty or as scripts only, open it with the browser tools, and use the browser only to read.
4. Read PDF and office files (docx, xlsx, pptx) with Python from the shell, using what is already installed; say which file and page each fact came from.
5. Check numbers, versions, and dates against the source itself, including ranges and end dates such as end of support.
6. Stop once each key fact is confirmed.
7. Give the confirmed facts each with its source and the date read, so the librarian can keep them for the next question.
