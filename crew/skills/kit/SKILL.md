# Kit

1. Read the kit and who holds what with `read_kit`, and a skill's whole text with `read_skill`.
2. A skill to make or change: write it with `write_skill` in the shape of the others, a procedure in English of numbered steps or short rules, with nothing the crew rules already say. Change an existing skill rather than adding one that does the same job.
3. A skill nothing in the crew's work uses any more: propose deleting it with `delete_skill`.
4. To undo the project's changes to one skill, or to the whole kit and who holds what, use `reset_skills`.
5. Who holds what: give a skill or MCP server only to the members whose own work uses it, one for each job, with `assign`; propose taking back what a member holds but its work does not use. A temp gets no MCP server.
6. An MCP server the kit lacks: name the smallest official or widely used one pinned to a version, with its source. Bringing it into the kit is the user's step.

The user approves or cancels each change on a card.
