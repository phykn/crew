# Report

Every result that is not code, such as a plan, research, a review, or a test run, goes into your handback body as the sections your instructions list, in their order, with tables for findings.

When the result is something later tasks should know (a decision, a reason, how to test, a fact the project relies on), also write it to the project wiki with `wiki_write`, under a title another member would search for. Keep only the current truth there: read the document first and replace what is no longer right.
